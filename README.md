# BribedIndia
**BribedIndia** maps corrupt patterns in India for SDG 16.  * **Reporting:** Anonymous logging of bribes, places, and departments.   * **Verification:** Tiered levels from unverified to confirmed.   * **Visuals:** Leaflet map and dashboards reveal trends.   * **Tech:** Built using React, Vite, Tailwind, and Supabase.
